# SocietyHub - Complete Build Plan 🚀

---

## Brand & Design Philosophy

### Core Design Principles
- **Minimal & Clean** - Let society content shine
- **Component Based** - Every element is reusable & themeable
- **Dark/Light Mode** ready from day one
- **Accessibility first** - inclusive for all users
- **Mobile first** always

### The Theming System
```
Every society gets their own "theme token" file:

{
  "society": {
    "name": "Manchester Sikh Society",
    "university": "University of Manchester",
    
    "colors": {
      "primary": "#003DA5",      // Main brand color
      "secondary": "#FFD700",    // Accent color
      "background": "#FFFFFF",   // App background
      "surface": "#F5F5F5",      // Cards/surfaces
      "text_primary": "#1A1A1A",
      "text_secondary": "#666666"
    },
    
    "typography": {
      "font_family": "Inter",    // Can swap per society
      "heading_weight": "700",
      "body_weight": "400"
    },
    
    "logo_url": "...",
    "banner_url": "...",
    "modules": ["events", "announcements", "chat", "religious"]
  }
}
```
> Just changing this one file completely transforms the app for each society - **zero design changes needed**

## Society Config File Template

```typescript
// config/societyConfig.ts
// THIS IS THE ONLY FILE THAT CHANGES PER SOCIETY

export const societyConfig = {
  
  // Identity
  name: "Manchester Sikh Society",
  shortName: "MancSS",
  university: "University of Manchester",
  description: "Connecting the Sikh community at UoM",
  founded: "2005",
  
  // Branding
  theme: {
    primary: "#003DA5",
    secondary: "#FFD700",
    accent: "#FF6B35",
    background: "#FFFFFF",
    surface: "#F8F9FA",
    textPrimary: "#1A1A1A",
    textSecondary: "#6B7280",
    success: "#10B981",
    warning: "#F59E0B",
    error: "#EF4444",
    darkBackground: "#0D0D0D",
    darkSurface: "#1A1A1A",
  },
  
  // Typography
  fonts: {
    heading: "Inter",
    body: "Inter",
    headingWeight: "700",
    bodyWeight: "400",
  },
  
  // Assets
  assets: {
    logo: require('./assets/logo.png'),
    banner: require('./assets/banner.png'),
    placeholder: require('./assets/placeholder.png'),
  },
  
  // Features/Modules (turn on or off per society)
  modules: {
    events: true,
    announcements: true,
    memberDirectory: true,
    chat: true,
    donations: true,
    religiousContent: true,   // Sikh/Islamic/Hindu etc
    sportsFixtures: false,
    academicResources: false,
    volunteerTracker: false,
    merchandise: false,
  },
  
  // Social Links
  social: {
    instagram: "@mancsikhs",
    facebook: "manchestersikhs",
    linktree: "mancsikhs",
    email: "committee@mancsikhs.com",
  },
  
  // Society Settings
  settings: {
    membershipFee: 5.00,
    currency: "GBP",
    requireUniversityEmail: true,
    allowGuestRSVP: false,
    maxMembersVisible: true,
  }
}
```
